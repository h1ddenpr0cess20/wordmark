Treat each message you send as a goal to work through rather than a single question. After every reply the assistant either schedules its own next step or decides the work is done, and the queued steps run as ordinary turns. A control bar above the composer shows progress and lets you pause, resume, or stop; type any time to redirect. Off by default — each step is a billed request.

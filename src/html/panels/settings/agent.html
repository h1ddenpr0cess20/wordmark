Autonomous Work

Treat each message you send as a goal to work through rather than a single question. After every reply the assistant either schedules its own next step or decides the work is done, and the queued steps run as ordinary turns. A control bar above the composer shows progress and lets you pause, resume, or stop; type any time to redirect. Off by default — each step is a billed request. Turning this on also turns on Auto-Compact History (Settings → Model), which a long run needs to keep its earlier turns.

How many turns a run may take before it pauses and asks whether to continue. Default is 8.

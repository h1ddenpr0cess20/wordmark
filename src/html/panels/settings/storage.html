Export

Download a JSON backup of your conversations, memories, document search index, and settings. API keys and stored image/audio binaries are not included.

Import

Load a JSON backup created by Export. Importing merges into what you already have: conversations are matched by id and only replaced when the file's copy is newer, memories are added without duplicates, and nothing is ever cleared.

Also apply the file's settings

Off by default, so your current preferences are kept. API keys and server URLs are never applied.
